# Support

Use GitHub issues for support related to this repository.

## Ask for help

Open a question issue when you need help with:

- Installing the package.
- Running the toy demo.
- Generating PSL features for your own PDB files.
- Understanding feature-table columns or expected outputs.
- Reproducing the documented benchmark scripts.

Please include the command you ran, your operating system, Python version, and
the relevant error message or output.

## Report bugs

Open a bug report when behavior appears incorrect or inconsistent with the
documentation. A good bug report includes:

- A minimal input file or toy example, if possible.
- The exact command or Python snippet.
- The expected behavior.
- The actual behavior.
- The package version or commit hash.

## Scope of support

The maintainer can help with the package API, scripts, tests, and documented
examples. Support for external benchmark datasets, third-party annotations, or
large unpublished protein collections may be limited to reproducible issues
that can be demonstrated with shareable inputs.

This project is maintained as open research software. Response times are not
guaranteed.
