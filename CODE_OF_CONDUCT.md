# Code of Conduct

This project aims to be a professional and constructive space for research
software collaboration.

Participants are expected to:

- Be respectful and specific in technical discussion.
- Focus criticism on code, documentation, tests, and scientific claims.
- Assume good faith while still asking for evidence when claims are unclear.
- Avoid harassment, personal attacks, discriminatory language, and disruptive
  behavior.
- Respect data licensing, privacy, and redistribution limits.

Maintainers may edit, close, or remove issues, pull requests, or comments that
are abusive, off topic, or inconsistent with these expectations. Serious or
repeated violations may lead to blocking from the repository.

To report a conduct concern, open a GitHub issue if public discussion is
appropriate. If the concern involves private information, contact the maintainer
through the repository owner's GitHub profile.
