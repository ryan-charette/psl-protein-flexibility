# Changelog

All notable changes to `psl-protein-flexibility` are tracked here.

This project follows a simple source-level changelog until formal versioned
releases begin.

## Unreleased

### Added

- Native self-contained PSL feature generation for local protein point clouds.
- Command-line feature generation for arbitrary PDB directories.
- Synthetic toy PDB examples and a runnable toy demo.
- JOSS manuscript source under `paper/`.
- Contribution, support, governance, conduct, issue-template, and release
  scaffolding.

### Changed

- Reframed the README around reusable software workflows rather than only
  manuscript reproduction.
- Updated benchmark scripts to use the native PSL implementation.

### Removed

- Removed the external `PSL.py` loader and old LaTeX manuscript artifacts.

## 0.1.0 - 2026-05-16

### Added

- Initial public repository for PSL protein-flexibility analyses.
- Reproduction scripts, metric snapshots, citation metadata, license, and
  benchmark-data documentation.
