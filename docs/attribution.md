# Attribution

This repository contains original software, experiment scripts, toy examples,
metric snapshots, and manuscript materials for PSL-based protein-flexibility
analysis.

The maintained PSL feature-generation implementation is native to this
repository and does not copy or redistribute third-party research code. The
software design is informed by the persistent sheaf Laplacian literature cited
in `paper/paper.md`.

Raw MDG_bfactor benchmark structures and annotation tables are third-party data
and are not redistributed. To reproduce the full manuscript analyses, place
those inputs at the paths documented in the top-level `README.md`.
